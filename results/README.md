# results/
Generated by `python -m model.experiments` and `python -m model.make_figures`.

- `experiment_grid.csv`  384 runs = 3 severities x 4 durations x 32 intervention packages
- `recommendations.csv`  cheapest feasible package meeting the service target (default 97 %, feasibility >= 3)
- `pareto_front.csv`     non-dominated packages (unmet critical demand vs cost)
- `figures/`             map, Pareto plot, hospital stock curves
